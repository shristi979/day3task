\# MY python project



\## Description

A python project to calculate deflection of beam. The folder contains beam.py which has all the functions to calculate the deflection of 5 beam cases. main.py runs for 3 different loads and spans. config.json has values of beam properties. 



\## Requirements

\-Python 3

\-NumPy

\-matplotlib



\## Instructions

\### 1. Clone repository

\### 2. Enter project directory

\### 3. Create virtual environment

\### 4. Activate venv

\### 5. Install dependencies

python -m pip install -r requirements.txt



\## Running project

python main.py
